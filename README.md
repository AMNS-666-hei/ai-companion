# AI 智能伴侣｜大模型应用实战项目
> 基于 DeepSeek LLM + Streamlit 搭建的个性化角色扮演对话应用
> 专注大模型应用开发、Prompt工程、多轮对话、本地持久化落地

## 📌 项目介绍
本项目是一款**基于大语言模型的AI个性化对话应用**，
通过自定义人设、角色限定提示词、多轮上下文记忆，
实现专属AI智能伴侣沉浸式对话体验，
完整落地大模型应用开发全流程。

## 🛠️ 技术栈
- 后端调用：DeepSeek LLM（deepseek-chat）
- 前端界面：Streamlit
- 网络请求：OpenAI SDK
- 配置管理：python-dotenv
- 数据存储：本地 JSON 文件持久化
- 开发语言：Python 3.10+

## ✨ 核心功能
1. 个性化人设定制
- 自定义伴侣昵称
- 自定义性格人设
- 强约束系统Prompt，保证角色不崩坏

2. 完整多轮对话
- 上下文记忆连贯对话
- LLM 流式逐字输出
- 拟人化语气+情绪emoji输出

3. 会话管理系统
- 新建独立会话
- 历史会话保存/加载/删除
- 单会话清空、全局配置重置
- 本地JSON持久化存储，重启不丢失

4. 工程化规范
- 环境变量统一管理密钥
- 分层代码结构：工具层/配置层/业务层
- 全局深色UI美化，交互体验优秀
- 完善异常捕获，程序稳定性强
